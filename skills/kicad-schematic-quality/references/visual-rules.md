# 시각 구성과 전페이지 판독

이 문서는 사람이 회로를 따라 읽을 수 있게 하는 배치·표현과 실제 출력 검토를 소유한다. 전기 PASS와 시각 PASS는 서로 대체하지 않는다.

## 공통 원칙

| 주제 | 기본 판단 | 피해야 할 오해 |
|---|---|---|
| 주 흐름 | 독자가 기능의 시작·단계·끝을 따라갈 수 있게 배치 | 모든 회로를 무조건 좌→우로 강제 |
| 기능 구역 | 입력·변환·출력·제어·보호·반환을 구분 | package 핀 순서가 기능 순서라고 가정 |
| 로컬 loop | 가까운 소회로는 실선으로 읽힘 | 이름 있는 모든 net을 label 섬으로 만듦 |
| 페이지 경계 | 실제 상대 시트·pin·방향·return을 표시 | 같은 이름이면 상대 목적지도 맞다고 가정 |
| 전원·반환 | 공급·일반 접지·부유·Kelvin·PE를 구분 | 미관 때문에 다른 기준점을 합침 |
| 반복 channel | 방향·간격·필드 표기는 일관되고 실제 pin은 보존 | `xN` 축약으로 검토 대상을 숨김 |
| 문자 | 실제 출력 배율에서 ref/value/pin/net/주석 판독 | 글꼴 축소로 한 장에 밀어 넣음 |
| 예외 | profile과 근거로 범위를 한정 | 교차선 0, label 0 같은 숫자를 보편화 |

주 흐름은 전력 회로에서 입력에서 출력으로 향하는 경우가 많지만 feedback·return·양방향 bus·ring에는 다른 방향이 자연스럽다. 선택한 방향과 예외는 페이지 계획에 기록한다. 용지, grid, font, 여백, 페이지 수는 profile 입력이다.

## 문자·도형·배선

- 외부 `Reference`와 `Value`, pin 이름·번호, net label, port, 주석의 semantic owner를 구분한다.
- wire가 문자획을 관통하거나 출력에서 잘리지 않는지 실제 glyph/stroke를 확대 판독한다.
- symbol body 내부 기능 표기와 정상 net label 접촉을 외부 field 결함과 구분한다.
- bbox·text layer·문자 경계 검사는 후보 탐색이다. 색상, 직교선, 빈 glyph, filled/closed body를 놓칠 수 있으므로 결함 0의 단독 근거가 아니다.
- 자동 검사에서 미일치·미지원·미포착인 항목은 `unknown`이며 0건으로 바꾸지 않는다.

확정된 외부 field 문자획 관통이나 잘림은 대상 field 교정 뒤 fresh native PDF에서 다시 0을 확인한다. 이동 전후 wire, symbol body, 다른 field, pin/net 계약이 변하지 않았는지 별도 대조한다.

## 페이지별 실제 판독

각 페이지에서 실제 GUI 상태와 native PDF 전체 페이지를 보고 필요한 확대 구역을 추가한다.

1. 제목 설명 없이 시작점·종점·주 경로를 찾는다.
2. 한 로컬 loop를 실제 ref.pin으로 따라간다.
3. 공급, power return, signal reference, 부유/Kelvin/PE 경계를 설명한다.
4. off-page port 하나를 상대 시트의 실제 수신 pin까지 찾는다.
5. ref/value/pin/net/극성/주석의 겹침·잘림을 본다.
6. wire와 body·field·다른 wire의 교차와 junction을 확대한다.
7. 반복 channel의 누락·뒤집힘·잘못된 return을 비교한다.

페이지 누락을 허용하지 않는다. GUI와 PDF는 렌더링이 다르므로 하나를 다른 하나로 대신하지 않는다. GUI 왕복을 실제로 하지 않았으면 했다고 기록하지 않는다.

## 읽기 과제와 독립성

전페이지 검토가 필요한 과제에서는 주 경로, feedback/보상 loop, 부유·Kelvin·PE return, off-page 목적지를 읽기 과제로 둔다. 작성자의 설명·의도된 결함 위치·자체 점수를 본 검토는 보충 검토이며 독립 holdout이 아니다.

작성자 자체 검토와 독립 검토를 receipt에서 구분한다. 필수 과제를 답하지 못했거나 도움 없이 읽는 것이 목표인데 설명이 필요했다면 시각 완료가 아니다.

## 점수 사용 원칙

점수표는 profile이 요구하거나 비교 평가가 필요할 때만 사용한다. 일상적인 작은 승인 변경마다 다중 모델·고정 횟수 평가를 강제하지 않는다. 점수 평균은 잘못된 pin, return, page link, 확정 문자 관통 같은 차단 결함을 상쇄하지 않는다.

정량 기준을 쓸 때에는 기준본, 출력 매체, 관찰자, 측정 방법, threshold 근거를 함께 고정한다. 다른 용지·font·grid·배율에 같은 간격값을 자동 승계하지 않는다.

## 회로도 밖의 경계

회로도에서 decoupling 부품이 옆에 보이거나 연결됐다는 사실은 PCB에서 충분히 가깝다는 증거가 아니다. 회로도 가독성, PCB placement·routing, 제조성, 동적 동작, 정격, 실물 안전은 별도 판정으로 보고한다.
