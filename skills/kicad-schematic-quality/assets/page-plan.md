# 회로도 페이지 사전 계획 양식

> 루트 회로도를 포함해 쓰기 허용 `.kicad_sch`마다 한 벌을 만들고 첫 CAD mutation 전에 검토·SHA 고정한다. 실제 ref.pin, 기능 구역, 양쪽 페이지 목적지를 적는다. 본문은 500자 이상이며 아래 `실선`, `포트`, `반환`, `검증` 주제를 구체적으로 채운다.

## 2. 실제 pin·부품 소유

| ref·unit | symbol·package | 물리 pin | name·type·극성 | net·기능 | 전압 영역·return | 확인 근거 |
|---|---|---:|---|---|---|---|
|  |  |  |  |  |  |  |

실제 runtime이 제공하는 unit·pin inventory, 배치본 endpoint 응답과 제조사 package 표를 대조한다. 특정 응답 필드가 항상 있다고 가정하지 않는다. 조회 성공이어도 pin 목록이 비거나 unit·상속 정보가 빠지면 다른 API·library source·배치본 확인 전에는 `미확인`이다. 일반 library 표나 도형만 본 값은 근거로 확정하지 않는다. 같은 ref의 모든 unit과 power pin이 정확히 한 번 소유되는지 적는다.

## 4. 반드시 실선으로 닫을 로컬 망

| 기능·net | 실제 ref.pin 묶음 | 실선 읽기 경로 | 예상 분기·junction | 금지 shortcut | 검사 방법 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

가까운 R/C, divider, filter, compensation, clamp, gate branch, sensing, Kelvin loop를 label로 분절하지 않는다. 예상 밖 wire 연장, 교차·분기 혼동, 같은 endpoint 중복을 readback과 native netlist에서 확인한다.

## 5. 공급·반환·절연 계약

| 공급·측정 node | 실제 source ref.pin | 소비 pin | 전압·절연 영역 | power 반환 | signal·Kelvin 반환 | 합치면 안 되는 기준점 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

부유 return, chassis/PE, 일반 GND를 미관상 합치지 않는다. `PWR_FLAG`, no-connect, pin type 변경이 필요하면 실제 전원·미사용 근거와 승인 범위를 적는다.

## 6. 페이지 포트 계약

| port·net | 이 페이지 ref.pin | 방향·전기형 | 영역·반환 | 상대 페이지 ref.pin | 양쪽 확인 방법 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

이름이 같은 것만으로 상대 연결을 합격시키지 않는다. 송신·수신 양쪽 실제 pin, 방향, 전압 영역, return과 native export를 대조한다.
