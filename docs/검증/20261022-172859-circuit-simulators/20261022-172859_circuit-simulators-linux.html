0. 요약 / 결론

클라우드 분석의 핵심 추천(Qucs-S + ngspice)은 타당하지만 이 시스템에는 더 나은 전제가 있었다. KiCad 10.0.6 AppImage가 ngspice 45.2를 번들하므로 내장 시뮬레이터는 추가 설치 없이 동작한다. 사용자 승인 아래 시스템 ngspice 44.2(apt), Qucs-S 26.1.1(AppImage 고정), LTspice 24.0.12(Wine)를 더해 네 경로를 만들었고, 검증 회로 5종 17개 측정 항목이 네 경로 모두 이론값 2% 이내로 일치했다. AI가 사용자 대신 전 과정을 수행하도록 Konnect MCP 시뮬레이션 도구 4종(KONNECT_SIM=1)과 프로젝트 스킬 kicad-simulation, 계약 문서, 회귀 테스트를 구축하고 기존 문서 9종에 통합했다.

1. 클라우드 분석 검증

2026-10-18 기준 클라우드 분석의 주장을 공식 자료와 이 호스트 실측으로 대조했다. 판정은 사실·부분 정정·부적합으로 나눈다.

주장판정근거
방법 B `apt install kicad ngspice libngspice0`이 시스템에 부적합apt kicad는 9.0.2. KiCad 10.0.6 AppImage가 이미 설치되어 있고 ngspice 45.2를 번들함(kicad-cli version --format about 실측)
Qucs-S는 Debian 패키지 또는 AppImage부분 정정Debian 공식 저장소에 qucs-s 없음. 개발자 OBS 저장소·GitHub AppImage·Flathub만 존재
Qucs-S AppImage에 ngspice 미포함사실공식 페이지 원문과 추출본 실측. Flatpak판은 ngspice 47 번들
Debian 13 ngspice 제공사실, 44.2+ds-1KiCad 번들 45.2보다 낮음. Qucs-S 마이크로스트립 해석은 45 이상 필요
PSpice for TI 타사 모델 시 3노드 프로브 제한사실TI SLYP725 원문 확인
PSpice for TI 주기적 온라인 라이선스 갱신부분 정정Cadence FAQ: 1년 단위 라이선스, 오프라인 실행 가능
LTspice는 Wine으로 실행사실, 실증ADI 공식 FAQ. 이 호스트에서 Wine 10.0으로 배치·GUI 기동 확인
QSPICE Windows 전용, 상업적 무료사실Qorvo 제품 페이지
ngspice는 PSpice/LTspice 호환, 암호화 모델 불가사실ngspice 공식 문서. KiCad 10은 호환 모드 설정 내장
Altium Mixed Simulation 먼저 확인해당 없음사용자 확인: Windows PC·VM·Altium 없음
핵심: 클라우드 분석이 몰랐던 사실은 "KiCad 10.0.6 AppImage에 ngspice 45.2가 이미 번들되어 있다"는 점과 "이 사용자는 Windows·Altium이 없다"는 점이다. 그래서 방법 B(apt kicad)와 Altium 1순위 권고는 이 시스템에 적용되지 않는다.

3.3 KiCad 편집기 시뮬레이터 GUI 검증 (ACUW 레인, 번들 ngspice)

KiCad 10.0.6 회로도 편집기 내장 SPICE 시뮬레이터(AppImage 번들 ngspice 45.2)가 Konnect MCP로 작성하고 .meas를 추가한 5개 회로도 사본을 ACUW 레인 kicad-smps-sync-gui(:182, 16G)에서 모두 실행했다. 측정 17개(.meas 15 + DERIVED 2) 중 17개가 사양 허용 오차(이론 대비 2%, 03 이득은 0.17 dB) 안에서 통과했다. 값은 GUI 콘솔의 .meas 출력을 클립보드로 받은 텍스트이며, GUI의 '현재 플롯을 CSV로 내보내기' 파일로 다시 계산한 값과 상대 2.4e-5 이내, 이전 단계의 번들 ngspice 45.2·시스템 ngspice 44.2 배치 값과 상대 4.5e-6 이내(교차 허용 1%)로 같았다. 03은 자동 생성 TRAN 탭에서 AC .meas가 출력되지 않아, GUI에서 AC 탭을 추가해 AC 측정 2개를 얻었다. 사용자 화면(:0)과 원본 kicad/는 쓰지 않았고, PID 491090 KiCad와 공유 Konnect 연결은 종료하거나 재시작하지 않았다.
