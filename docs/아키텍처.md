# 아키텍처

## 목표

자연어 작업을 MCP tool call로 변환하되, 설계 데이터의 정본은 KiCad 파일과 실제 KiCad 10 엔진에 둡니다.

```text
AI / MCP client
      |
      | initialize, tools/list, tools/call
      v
Konnect MCP router
      |
      +-- schematic S-expression engine -- atomic write --> *.kicad_sch
      |
      +-- KiCad 10 IPC API ------------ NNG/protobuf --> PCB Editor
      |
      +-- kicad-cli -------------------- process ------> ERC/DRC/export
      |
      +-- observability ---------------- JSONL --------> .runtime-home
```

## 데이터 경계

| 경계 | 정본 | 실패 시 원칙 |
|---|---|---|
| 회로도 편집 | `.kicad_sch` | 임시 파일, fsync, rename을 통한 atomic write 유지 |
| PCB 실시간 편집 | 실행 중인 KiCad 10 PCB Editor | IPC 실패를 파일 직접 변경으로 조용히 대체하지 않음 |
| ERC/DRC | KiCad 10 `kicad-cli` 결과 | exit code와 report를 함께 보존 |
| 제조 산출물 | 검증된 PCB commit에서 생성한 Gerber/drill/BOM/position | 입력 commit과 생성 명령을 manifest에 기록 |
| MCP 계약 | tool/schema/config/CLI | 호환성 또는 명시적 migration 필요 |

## Source와 개발 원격

```text
KiCad official GitLab
    |
    +-- latest stable tag --> upstream/kicad (read-only)

mixelpixx/Konnect (official upstream)
    |
    +-- sync/review --> hanall/Konnect (fork, Actions disabled)
                           |
                           +-- hanol-dev/* --> 성능·안정성·도구 개선
```

root 저장소와 Konnect fork 모두 GitHub Actions를 사용하지 않습니다. 검증 정본은
개발 호스트에서 실행한 `make check-local` 결과이며, root gitlink는 검증된 Konnect
fork commit만 가리킵니다.

## 안전한 기본 실행

구 Konnect v0.2.2는 첫 MCP 실행 때 사용자 설정을 자동 수정했습니다. 0.13.0 계열은 명시적 `init`을 사용하지만 같은 격리 경계를 유지합니다. 이 프로젝트의 `.mcp.json`은 binary를 직접 실행하지 않고 `scripts/run-konnect.sh`를 호출합니다. wrapper는 HOME과 XDG state를 `.runtime-home`으로 격리해 실제 사용자 설정을 보존합니다.

## 개선판 추가 경계

- 뷰어: S-expression 원본은 읽기 전용, 임시 snapshot에서 실제 `kicad-cli` SVG를 생성합니다. 임의 외부 bind 대신 `127.0.0.1`과 난수 capability 경로를 사용합니다. 페이지·상태·SVG·브라우저 로딩 ACK를 함께 확인해야 ready입니다.
- whole-footprint IPC: 같은 document의 메모리 snapshot과 KIID를 대조해 protobuf가 보존하지 못하는 point·group·units 등은 쓰기 전에 거부합니다. 닫힌 PCB의 별도 opt-in은 원문 보존·revision·CAS·readback을 거칩니다.
- raw 오류와 적용 결과: 호출 성공, 실제 적용, 원복, 미확정 상태를 구분합니다. rollback 도중 외부 writer가 바꾼 파일을 이전 snapshot으로 덮지 않습니다.
- 런타임 HOME: 기본 `.runtime-home` 외 격리는 `KONNECT_RUNTIME_HOME`의 `.artifacts` 하위 canonical 디렉터리만 허용합니다. 심볼릭 링크 탈출은 거부합니다.
- 공개 기능 시험: catalogue(형식/거부), headless(회로/라이브러리), PCB(GUI/IPC), service(제조/네트워크/라우터)의 ledger를 같은 바이너리 SHA에 결속해 병합합니다.
