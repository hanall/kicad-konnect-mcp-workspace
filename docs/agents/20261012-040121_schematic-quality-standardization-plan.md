# 회로도 표준 품질 스킬 구축·세 기존 스킬 개선 계획

작성: 2026-10-12 04:01:21 KST · 상태: 구현·검증 진행 중

## 요청과 범위

사용자는 배터리 프로젝트의 회로도 품질 방법을 이 저장소에 프로젝트 독립적인 표준 스킬로 구축하도록 승인했다. 이어 `konnect`, `kicad-schematic`, `kicad-review`의 전수 조사·필요 개선과 오류·무결성·변이 검증을 요청했다.

- 정본: `skills/kicad-schematic-quality/` 하나. `.claude/skills/`와 `.agents/skills/`에 상대 링크를 둔다.
- 공통 절차·회로 유형별 profile·도구 실행 환경을 분리한다. SMPS 정격·A3·19쪽·특정 이격값은 공통 상수가 아니다.
- 외부 글로벌 스킬과 upstream submodule은 수정하지 않는다. 세 기존 스킬의 교정은 새 표준 스킬의 이식 가능한 오버레이와 이 프로젝트의 호출 지침에서 적용한다.
- 대상 저장소의 기존 미커밋 변경 12경로를 보존한다. 기존 파일은 `AGENTS.md`, `README.md`, `Makefile`의 이번 기능용 작은 변경만 허용한다. `CLAUDE.md`는 기존 symlink를 유지한다.
- 새 의존성 설치·전역 설정 변경·기존 GUI/연결 재시작·commit/push·제조/통전은 이 작업 범위가 아니다. GitHub Actions나 Git LFS는 도입하지 않는다.

## 구현 원칙

1. 시트 계획·pin/net/값/footprint·실선·반환·전압 영역을 입력 계약으로 받는다.
2. 쓰기 어댑터는 승인된 project root와 파일 목록만 취급하고, 현재 schema로 확인하지 않은 쓰기는 거부한다. CAD 직접 텍스트 생성은 하지 않는다.
3. 범용 검사기는 외부 제품 레포가 아니라 명시한 project root·registry·입력 산출물에 결속한다. PDF의 구조 검사를 육안·전기·제조 합격으로 확대하지 않는다.
4. 문서 개선은 실제 동작과 대응시킨다. 예: 모든 이름 있는 망을 라벨로 바꾸기, 임의 `PWR_FLAG`, 회로도 거리로 PCB/정격 판정, 저장 상태 확인 없는 쓰기/리뷰, 고정 도구 수, 누락 검사를 PASS로 세는 규칙을 바로잡는다.
5. 시험용 CAD는 공식 MCP 또는 승인 GUI에서만 새로 작성한다. 제품 회로·고객 자료·제조사 원문을 배포용 예제로 복제하지 않는다.
6. CLI 검증은 설치된 구독 인증을 확인한 경우에만 실행하고 API key 경로를 사용하지 않는다. 실제 모델 미관측을 임의 모델명으로 채우지 않는다.

## 실행 순서

```text
baseline -> source-audit -> portable-core -> unit/mutation
         -> isolated-authoring -> native/GUI/review
         -> independent-audit -> local-gates -> closeout
```

시작 baseline과 원 rc는 `.artifacts/20261012-040121-standard-quality/`에 보존한다. 최종 사용자 인계용 요약·검증 계약·지원 범위는 추적 가능한 문서에 남긴다. 현재 실제 KiCad 10.0.6/Konnect 0.13.0+hanall.1 조합만 관측했으며 다른 OS·도구·모델·모든 회로에 대한 보편 성공을 주장하지 않는다.

## 승인·경계

현재 두 프로젝트의 공유 GUI 편집 승인은 표준 스킬을 설치하는 다른 프로젝트에 자동 부여하지 않는다. 사용자 요구·설계 계약·핀 원문·현재 도구 환경은 여전히 입력으로 필요하다. 읽기 전용 검토는 모델이 좋은 수정을 제안하더라도 CAD를 쓰지 않는다.
