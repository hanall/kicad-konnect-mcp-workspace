0. 결론

개발 기반을 로컬 검증 체계로 종결했습니다. KiCad는 공식 최신 안정 릴리스만 추적하고, Konnect는 공식 upstream과 hanall 개선 fork를 분리했습니다. root와 fork 모두 GitHub Actions가 비활성화되어 새 push가 Actions 과금을 발생시키지 않습니다.

1. Source 계약

KiCad official GitLab | +-- latest stable tag (exclude *.99.0) --> upstream/kicad [read-only] mixelpixx/Konnect [official upstream] | +-- review and sync --> hanall/Konnect [development fork] | +-- hanol-dev/* --> performance and reliability work
Source정본자동화
KiCad공식 GitLab tag와 commitmake check-updates, make update-kicad
Konnect upstreammixelpixx/Konnect의 release tagupstream_tag와 upstream_commit 보존
Konnect 개발hanall/Konnect의 검증된 fork commitmake setup-konnect-dev
버전 정책: “새 버전”은 공식 안정 릴리스로 해석했습니다. KiCad의 9.99.0, 10.99.0 같은 개발 태그는 자동 반영하지 않으며, 미래의 새로운 안정 major/minor/patch는 선택합니다.

5. 남은 범위

KiCad 10 runtime은 설치하지 않았습니다. 이 작업은 source·MCP 개발 기반 구축입니다. 따라서 실제 KiCad 10 GUI/IPC, kicad-cli ERC/DRC, Gerber·drill 생성은 아직 실기 검증이 아닙니다.

6. 롤백

root 구조 변경은 commit 33cf158을 기준으로 되돌릴 수 있습니다. 다만 GitHub Actions 재활성화와 workflow 복원은 사용자의 과금 방침에 반하므로 수행하지 않습니다. Konnect 개발 fork는 공식 upstream을 변경하지 않으며, root gitlink를 이전 검증 commit으로 돌리면 파생 변경을 격리할 수 있습니다.
