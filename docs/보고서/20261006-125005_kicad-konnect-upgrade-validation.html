4. 사용자 화면 데모와 관측 시간

J1 +5V/GND, R1 470 ohm, D1 LED(pin 1=K, pin 2=A), C1 100nF, 40×25 mm 보드를 MCP로 생성·배치·배선했습니다. 4 footprint, 8 pad, 9 track, 0 via, 3 net, GND zone 1, 미배선 0입니다. 보호 파일 직접 문자열 편집은 하지 않았습니다.

DRC 0E/6W -> field sync -> 0E/2W -> lossless refresh -> 0E/0W
MCP -> KiCad IPC -> save -> CLI ERC/DRC -> readback

E는 오류, W는 경고입니다. 경고 무시 설정으로 숨기지 않고 Description 필드와 library geometry를 교정했습니다. 개선 직전 원본 대비 기존 R1 parent/pad UUID 및 모든 9 trace의 UUID·좌표·net·폭을 확인했습니다. 초기 9시 관측과 더 늦은 preimage 사이의 UUID 변화를 이번 closed refresh가 만든 것으로 단정하지 않았습니다.

전체 기능 재현 명령과 migration은 검증 계약에, 원 증거의 해시는 SHA 목록에 있습니다. 원본 JSONL·CLI 로그·영상은 Git 제외 artifact에 보존했습니다. 영상은 실제 개선 시연 녹화이며 실시간 대기를 포함한 1,548.375초/8,114,474B입니다.

복구: GUI와 exact target을 먼저 확인하고 회로 백업 .artifacts/20261006-upgrade/backups를 보존합니다. 공유 checkout에 broad reset/stash를 하지 않습니다. source rollback은 별도 revert와 root gitlink/lock의 동시 갱신 후 재검증합니다. 이전 KiCad /opt/kicad/10.0.5는 보존했고, 되돌릴 때 wrapper 8개·desktop·manifest를 함께 검증해야 합니다. Freerouting은 artifact 전용 런타임이므로 시스템 Java/alternatives 변경은 없습니다.

기존 MCP 프로세스의 실행 이미지와 새 디스크 binary를 구분했습니다. 최종 검증 서버는 fresh STDIO 프로세스의 exe SHA·initialize·get_installation_info commit을 대조했습니다. 구 0.2.2 연결을 최신으로 오인하지 않도록 기존 클라이언트 연결을 재시작하고 같은 정보를 확인하세요.
