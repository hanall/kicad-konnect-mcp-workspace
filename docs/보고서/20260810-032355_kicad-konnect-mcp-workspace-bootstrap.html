5. 남은 범위와 리스크

아직 실제 보드 E2E 완료가 아닙니다. 이 호스트에는 KiCad와 kicad-cli가 설치되지 않았고 Debian 13 기본 APT 후보는 9.0.2입니다. 따라서 KiCad 10 GUI/IPC, 실제 ERC/DRC, Gerber 생성은 실행하지 않았습니다.
리스크등급대응
Konnect beta 및 Linux 현장 검증 부족중실제 KiCad 10 fixture로 GUI/CLI 교차검증
AGPL 파생·network 제공 의무중공개 source 또는 commercial license 검토
ERC/DRC를 안전 보증으로 오해중정격, 열, 극성, EMC, 제조사 DFM 별도 검토

Rollback

Root 변경은 Git commit 단위로 되돌립니다. Submodule upgrade는 upstreams.lock.json과 gitlink를 함께 이전 commit으로 복구합니다. 실제 회로 편집은 원본 commit과 제조 artifact manifest를 보존한 뒤 수행합니다.
