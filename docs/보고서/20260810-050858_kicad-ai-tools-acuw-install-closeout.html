5. 제한 및 정리

항목처리
Konnect 성숙도upstream 표기상 beta다. 실제 제조 전에는 ERC/DRC뿐 아니라 전원·극성·footprint·BOM·제조사 규칙을 별도 검토한다.
ACUW 종료 경고/proc 탐색 중 권한·프로세스 소멸 경고가 있었으나 최종 레인은 stopped, 창 0개로 확인했다.
stale API socket프로세스·listener 부재를 확인한 뒤 /tmp/kicad/api.sock.stale-acuw-20260810-050537로 복구 가능하게 격리했다.
원격 반영외부 push는 사용자 승인 범위 밖이므로 수행하지 않는다.
